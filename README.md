# 自選股盤後

台股自選股盤後閱讀網頁:基本面、營收、籌碼、新聞、產業與熱力圖。只支援台股(上市、上櫃、興櫃、ETF)。

## 啟動

需要 Node.js 18 以上,不需要安裝任何套件。

- Windows:雙擊 `start.bat`
- 其他:`node server.js`,瀏覽器開 http://localhost:3000

可選:設定環境變數 `FINMIND_TOKEN`(FinMind 註冊後的 token)可提高歷史資料的查詢額度。

## 功能

- 輸入代號或名稱加入自選股,或匯入文字檔(一行一檔,支援 UTF-8 與 Big5)
- 自選股總覽、個股頁(概況、營收、財報、籌碼、產業、新聞)
- 台股總覽、市值熱力圖、產業熱力圖(含產業鏈、電子產業細分、概念股、集團股)
- 個股分類與題材、主要業務
