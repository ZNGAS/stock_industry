# 台股產業分析

台股產業分析:自選股盤後閱讀、基本面、營收、籌碼、新聞、產業與熱力圖。只支援台股(上市、上櫃、興櫃、ETF、特別股等)。

## Windows 免安裝版(一個資料夾 + 一個 exe)

這個倉庫本身就是可以直接用的資料夾:下載後解壓縮(GitHub 頁面 Code → Download ZIP,或 `git clone`),雙擊最外層的 **`stock-industry.exe`** 即可,不需要安裝 Node.js。

```
台股產業分析/
  stock-industry.exe    啟動器(雙擊這個)
  server.js、public/、assets/、…    程式檔
  data/                 自選股清單、設定、資料快取(第一次執行時建立,更新不會動到)
```

- 在獨立的應用程式視窗中執行(沿用 Windows 內建的 Edge,沒有網址列與分頁),關閉視窗就會結束程式。
- 第一次開啟會在桌面建立「台股產業分析」捷徑,之後從捷徑開啟即可。
- 每次開啟都會先到 GitHub 檢查有沒有新版(比對最新 commit),有就自動下載並更新資料夾裡的程式檔(包含 exe 本身,新的啟動器下次開啟生效),進度會顯示在視窗中。沒有網路時直接用目前的版本。
- 想略過檢查更新或重建捷徑,可在捷徑目標後加上 `--no-update`、`--shortcut`。
- 啟動紀錄在 `data/launcher.log`;若視窗顯示錯誤,可以把這個檔案附上回報。
- **打不開或更新壞掉時**:把 `修復更新.bat` 放進這個資料夾(下載的資料夾本來就有)雙擊,它會從 GitHub 重新下載最新版並覆蓋程式檔與 exe,`data/` 裡的自選股與設定不會被動到。
- 第一次執行時 Windows SmartScreen 可能顯示「Windows 已保護您的電腦」(執行檔沒有數位簽章):點「其他資訊」再點「仍要執行」。部分防毒軟體對打包的執行檔也可能誤報。不要放在 `C:\Program Files` 這類需要管理員權限的位置。
- 倉庫如果是**私人**的,啟動器在公開連不上時,會改用這台電腦上 git 已登入的 GitHub 憑證(也可設環境變數 `SI_TOKEN`,或把 token 放在 `data/github-token.txt`)。要分享給別人使用,倉庫需設為公開。
- 開發者:改了 `launcher/launcher.js` 才需要執行 `npm run build:exe` 重新打包,並把新的 `stock-industry.exe` 一起提交;只改程式檔不用動 exe。

## 啟動

需要 Node.js 18 以上,不需要安裝任何套件。

- Windows:雙擊 `start.bat`
- 其他:`node server.js`,瀏覽器開 http://localhost:3000

可選:設定環境變數 `FINMIND_TOKEN`(FinMind 註冊後的 token)可提高歷史資料的查詢額度。

## 功能

- 輸入代號或名稱加入自選股,或匯入文字檔(一行一檔,支援 UTF-8 與 Big5)
- 自選股總覽、個股頁(概況、營收、財報、籌碼、產業、新聞)
- 個股的分類與題材:上市別、產業股、集團股、題材、主要業務
- 台股總覽、市值熱力圖、產業熱力圖(產業別、產業鏈、電子產業細分、概念股、集團股)
- 漲停、跌停價以紅、綠色塊標示(紅漲綠跌)

## 資料來源與更新時間

「官方更新時間」是資料來源自己的更新節奏;「本機快取」是這個程式抓到資料後暫存多久,期間內重複查看不會再向外部查詢。

### 官方資料(以此為準)

| 內容 | 來源 | 官方更新時間 | 本機快取 |
| --- | --- | --- | --- |
| 收盤行情、成交量值 | 證交所官網「每日收盤行情」(MI_INDEX)、櫃買中心官網「上櫃股票每日收盤行情」;官網沒資料時退回兩家的 OpenAPI | 每個交易日收盤後(官網比 OpenAPI 早,OpenAPI 的櫃買檔案有一萬兩千多筆、下載常很慢) | 5 分鐘,另存磁碟快照,網路慢時先用上次的 |
| 本益比、淨值比、殖利率 | 證交所、櫃買中心 | 每個交易日收盤後 | 5 分鐘 |
| 三大法人買賣超(個股) | 證交所 T86、櫃買中心 | 每個交易日收盤後,晚於行情 | 10 分鐘 |
| 融資融券餘額 | 證交所、櫃買中心 | 每個交易日收盤後,晚於行情 | 10 分鐘 |
| 加權指數、市場成交值、三大法人金額 | 證交所 FMTQIK、BFI82U | 每個交易日收盤後 | 10 分鐘 |
| 櫃買指數、三大法人金額 | 櫃買中心 | 每個交易日收盤後 | 10 分鐘 |
| 公司基本資料 | 證交所、櫃買中心 | 不定期 | 5 分鐘(隨行情載入) |
| 每月營業收入 | 證交所、櫃買中心(公開資訊觀測站申報) | 每月,公司於次月 10 日前申報 | 30 分鐘 |
| 累計 EPS(核對用) | 證交所、櫃買中心 | 每季,財報公告後 | 6 小時 |
| 重大訊息 | 證交所、櫃買中心 | 即時,但官方 OpenAPI 只提供當天 | 10 分鐘 |
| 除權息預告 | 證交所、櫃買中心 | 公告後 | 2 小時 |

漲停、跌停價由前一日收盤價與台股升降單位計算,不是官方欄位。

**櫃買行情的成交量**:櫃買官網的「上櫃股票每日收盤行情」不含盤後定價交易,成交股數比 OpenAPI 的總量略小;價格、漲跌、開盤完全一致(逐檔核對 1013 檔)。個股與榜單的成交量仍會以 Yahoo 一般整股數字為準。

**成交量口徑**:證交所、櫃買中心的「成交股數」含一般整股、盤中與盤後零股、盤後定價、鉅額(含股票組合,官方不逐檔公布),比 Yahoo 奇摩股市與盤中即時行情顯示的「一般整股成交量」大一些(例如台積電 2026/10/02:官方 15,792 張,Yahoo 13,902 張)。顯示個股、自選股、排行與成分股表時,成交量與成交值採 Yahoo 的一般整股數字(抓不到時退回官方總量);股價走勢頁的成交量圖是歷史資料,維持證交所口徑。Yahoo 數字每 5 分鐘更新一次快取。

## 什麼時候會去查詢資料

- 程式不會在背景自動輪詢。打開網頁、切換頁面或按「重新整理」時,本機伺服器才會向上述來源查詢,並暫存到「本機快取」所列的時間。
- 伺服器啟動時會預先載入一次行情與產業分類。
- 網頁開著不動不會自動更新,需要重新整理頁面。瀏覽器端另外有 5 分鐘的暫存。
- 若資料來源暫時連不上,會顯示先前存下的資料並提示。
- FinMind 不帶 token 每小時約 300 次查詢上限;Yahoo 分類第一次載入會連續抓約 350 個頁面,之後 24 小時內使用快取。
- 快取檔存放在專案的 `.cache/`(已列入 `.gitignore`),可以隨時刪除,下次使用時會重新抓取。
