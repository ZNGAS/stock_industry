# 台股產業分析

台股產業分析:自選股盤後閱讀、基本面、營收、籌碼、新聞、產業與熱力圖。只支援台股(上市、上櫃、興櫃、ETF、特別股等)。

## Windows 免安裝版(資料夾 + 自動更新)

一個資料夾,裡面只有一個 `stock-industry.exe`,不需要安裝 Node.js:

```
stock-industry/
  stock-industry.exe   啟動器
  app/                 程式檔(更新時整個替換)
  data/                自選股清單、設定、資料快取(更新不會動到)
  README.txt
```

- 雙擊 `stock-industry.exe`。第一次開啟會在桌面建立「台股產業分析」捷徑,之後從捷徑開啟即可。
- 每次開啟都會先到 GitHub 檢查有沒有新版(比對最新 commit),有就自動下載並替換 `app/`,再啟動網頁。沒有網路時直接用目前的版本。
- 關閉黑色視窗就會停止。想略過檢查更新或重建捷徑,可在捷徑目標後加上 `--no-update`、`--shortcut`。
- 這個 GitHub 倉庫如果是**私人**的,啟動器在公開連不上時,會改用這台電腦上 git 已登入的 GitHub 憑證(也可設環境變數 `SI_TOKEN`,或把 token 放在 `data/github-token.txt`)。要分享給別人使用,倉庫需設為公開。
- 第一次執行時 Windows SmartScreen 可能顯示「Windows 已保護您的電腦」(執行檔沒有數位簽章):點「其他資訊」再點「仍要執行」。部分防毒軟體對打包的執行檔也可能誤報。
- 啟動器本身(`stock-industry.exe`)不會自動更新,只有 `app/` 裡的程式會。
- 自行組出這個資料夾:先把程式碼推上 GitHub,再執行 `npm run build:dist`(輸出在 `dist/`,另有 `stock-industry-win.zip`)。

## 啟動

需要 Node.js 18 以上,不需要安裝任何套件。

- Windows:雙擊 `start.bat`
- 其他:`node server.js`,瀏覽器開 http://localhost:3000

可選:設定環境變數 `FINMIND_TOKEN`(FinMind 註冊後的 token)可提高歷史資料的查詢額度。

## 功能

- 輸入代號或名稱加入自選股,或匯入文字檔(一行一檔,支援 UTF-8 與 Big5)
- 自選股總覽、個股頁(概況、營收、財報、籌碼、產業、新聞)
- 個股的分類與題材:上市別、產業股、集團股、題材、主要業務
- 台股總覽、市值熱力圖、產業熱力圖(產業別、產業鏈、電子產業細分、概念股、集團股)
- 漲停、跌停價以紅、綠色塊標示(紅漲綠跌)

## 資料來源與更新時間

「官方更新時間」是資料來源自己的更新節奏;「本機快取」是這個程式抓到資料後暫存多久,期間內重複查看不會再向外部查詢。

| 內容 | 來源 | 官方更新時間 | 本機快取 |

| 本益比、淨值比、殖利率 | 證交所、櫃買中心 | 每個交易日收盤後 | 5 分鐘 |

| 融資融券餘額 | 證交所、櫃買中心 | 每個交易日收盤後,晚於行情 | 10 分鐘 |

| 每月營業收入 | 證交所、櫃買中心(公開資訊觀測站申報) | 每月,公司於次月 10 日前申報 | 30 分鐘 |
| 累計 EPS(核對用) | 證交所、櫃買中心 | 每季,財報公告後 | 6 小時 |

| 興櫃行情、基本資料、月營收 | 櫃買中心 | 同上市櫃,興櫃行情以前日均價為基準 | 同上 |

漲停、跌停價由前一日收盤價與台股升降單位計算,不是官方欄位。

**成交量口徑**:證交所、櫃買中心的「成交股數」含一般整股、盤中與盤後零股、盤後定價、鉅額(含股票組合,官方不逐檔公布),比 Yahoo 奇摩股市與盤中即時行情顯示的「一般整股成交量」大一些(例如台積電 2026/10/02:官方 15,792 張,Yahoo 13,902 張)。顯示個股、自選股、排行與成分股表時,成交量與成交值採 Yahoo 的一般整股數字(抓不到時退回官方總量);股價走勢頁的成交量圖是歷史資料,維持證交所口徑。Yahoo 數字每 5 分鐘更新一次快取。

### 歷史資料

| 內容 | 來源 | 更新時間 | 本機快取 |
| --- | --- | --- | --- |
| 股價歷史、成交量 | [FinMind](https://finmindtrade.com/) | 每個交易日收盤後 | 20 分鐘 |
| 三大法人、融資券、外資持股(個股歷史) | FinMind | 每個交易日收盤後 | 20 分鐘 |
| 月營收歷史 | FinMind | 每月,隨公司申報 | 3 小時 |
| 季財報、資產負債、現金流、股利 | FinMind | 每季財報公告後(一般公司約:Q1 5/15、Q2 8/14、Q3 11/14、年報 3/31 前) | 6 小時 |

FinMind 的資料整理自交易所與公開資訊觀測站。最新一筆若比官方資料舊,程式會以官方當日資料補上;月營收與累計 EPS 會與官方數字核對,結果顯示在頁面上。部分金融股的新一季 EPS 在 FinMind 尚未更新時,以「歸屬母公司淨利 ÷ 股數」估算並標示「估」。

## 什麼時候會去查詢資料

- 程式不會在背景自動輪詢。打開網頁、切換頁面或按「重新整理」時,本機伺服器才會向上述來源查詢,並暫存到「本機快取」所列的時間。
- 伺服器啟動時會預先載入一次行情與產業分類。
- 網頁開著不動不會自動更新,需要重新整理頁面。瀏覽器端另外有 5 分鐘的暫存。
- 若資料來源暫時連不上,會顯示先前存下的資料並提示。
- FinMind 不帶 token 每小時約 300 次查詢上限;Yahoo 分類第一次載入會連續抓約 350 個頁面,之後 24 小時內使用快取。
- 快取檔存放在專案的 `.cache/`(已列入 `.gitignore`),可以隨時刪除,下次使用時會重新抓取。
